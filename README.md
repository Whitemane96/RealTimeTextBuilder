# Real-Time text builder.

Simple tool written in JavaScript that allows you to input text from multiple HTML elements and shows you a real-time preview of your text.

## Includes

- Live preview as you type and/or make selections.
- Grammar tools:
    - Includes a function that changes articles and pronouns based on gender.
    - A function that creates a list from an array of elements and formats it with proper wording.
    - Added a button that creates multiple inputs as needed.
    - Date formatting.
- Responsiveness.
- 2 columns layout display.

## Usage

Just open the index.html and that should be it. Unless you want to start a localhost with your preferred method.
